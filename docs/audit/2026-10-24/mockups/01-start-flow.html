Starting a test with the fewest taps

Phones: GO only opens a sheet, then a connection tile, then “Start test”, then a location prompt or map pin: 4–5 taps before anything measures. Desktop: the lime GO stays grey until the left form is complete, and “Please select ↓” bounces forever. Detection already knows the provider and district for most visitors.

GO opens a short sheet holding only the unanswered question (usually connection). Picking a tile starts the test, so it’s GO + 1 tap, and the same sheet handles an unknown provider.

Recommendation: C: ask only what’s missing, and let the answer start the test. It brings a phone test down to GO + 1 tap without guessing the connection, keeps the dial as the hero, and the same component replaces the desktop left form.
